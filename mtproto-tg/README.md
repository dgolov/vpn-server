# Развёртывание MTProto-прокси для Telegram

Полное руководство по запуску собственного MTProto-прокси сервера для Telegram с использованием Docker.

---

## 1. Требования

Перед началом убедитесь, что у вас есть:

* VPS / сервер с публичным IP
* Установленный Docker
* Открытый порт (рекомендуется `443`)

---


## 2. Запуск MTProto-прокси

```bash
docker run -d -p 443:443 \
-e SECRET=$(head -c 16 /dev/urandom | xxd -ps) \
--name mtproto-proxy \
--restart always \
telegrammessenger/proxy
```

---

## 3. Получение данных для подключения

Посмотреть логи контейнера:

```bash
docker logs mtproto-proxy
```

В логах появится строка:

```text
tg://proxy?server=<IP>&port=443&secret=<SECRET>
```

---

## 4. Подключение к прокси

### Способ 1 (рекомендуется)

1. Скопируйте ссылку из логов
2. Откройте её на устройстве с Telegram
3. Нажмите **Подключить**

---

### Способ 2 (вручную)

1. Откройте Telegram
2. Перейдите:
   **Настройки → Данные и память → Прокси**
3. Нажмите **Добавить прокси**
4. Выберите **MTProto**
5. Введите:

   * **Server**: IP вашего сервера
   * **Port**: `443`
   * **Secret**: значение из логов

---

## 5. Возможные проблемы и решения

### Ошибка `invalid reference format`

Причина: неправильные переносы строк или лишние символы
Решение: вставить команду одной строкой

---

### Не удаётся подключиться

* Проверьте открыт ли порт `443`
* Убедитесь, что сервер доступен извне
* Проверьте правильность `SECRET`

---

### Порт уже занят

Ошибка:

```text
port is already allocated
```

Решение:

```bash
docker stop mtproto-proxy
docker rm mtproto-proxy
```

Или использовать другой порт:

```bash
docker run -d -p 1443:443 ...
```

---

### Прокси подключается, но не работает

* Сервер может быть заблокирован
* Низкое качество VPS или плохой канал
